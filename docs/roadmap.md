# Roadmap

## Production readiness

Provision isolated cloud projects, enforce App Check, complete admin mutation services/forms, add Cloud Run image pipeline with WIF, browser E2E, Storage emulator tests, accessibility audit, security review, monitoring, backups, and operational runbooks.

## Next product increments

Add leave balance accounting/workflows, employee profile self-service, private employment documents and payslips, notification preferences, report exports, precomputed summaries, MFA/SSO, delegated admin scopes, and Swedish holiday calculation.

Later candidates include payroll-provider integration, expenses, accounting, and native experiences only after separate architecture/privacy decisions. Candidate migration or automatic conversion remains intentionally excluded.
